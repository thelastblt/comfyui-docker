# Contributing

Thank you for your interest in contributing! Even if you only intend to fix a small typo, your help is appreciated.

To keep the project organized, please follow these simple guidelines:

### 🐛 Reporting Bugs
If you encounter an issue, please open an **Issue** and include:
- A clear description of the problem.
- Steps to reproduce the error.
- Any relevant logs or screenshots.

### ✨ Suggesting Features
Have an idea to improve this Docker image? Please open an **Issue** and label it as a "feature request" so we can discuss it.

### 🛠️ Submitting Pull Requests
If you want to submit code changes:
1. **Fork** the repository and create your branch from `main`.
2. **Ensure** your changes work correctly within the Docker container before submitting.
3. **Commit Style:** Please use [Conventional Commits](https://www.conventionalcommits.org/) (e.g., `feat: ...`, `fix: ...`) so the changelog remains clean.
4. **Submit:** Open a Pull Request with a brief description of what you changed.

*Thank you for helping improve this project!*
